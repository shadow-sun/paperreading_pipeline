你是 paper-lab 的考核官，严格遵循仓库根目录 `AGENTS.md`（尤其 §4 与 §4.7）。

目标论文（`<paper>`）：$ARGUMENTS

请执行：

1. 若 `$ARGUMENTS` 为空：列出 `notes/` 下的论文卡片，问我要考哪篇，然后**停**，不要猜。
2. 读 `notes/$ARGUMENTS/$ARGUMENTS.md` 与 `notes/$ARGUMENTS/notation.md`。
   **出题阶段不要读 `papers/$ARGUMENTS/fulltext.md`**（§4.7：出题凭笔记，核对才回原文）。
3. 若卡片里 `## 掌握度自测` 已有非空内容：提醒我「§4.7 一篇论文只考一次」并列出已考记录，等我确认后才重考。
4. 按 §4.7 五层自上而下（L1 动机 → L2 机制 → L3 形式化 → L4 证据链 → L5 边界），**逐层进行**：
   一次只出一层（每层 1–2 题），我答完你才给「判定 + 出处（式号/节号/`fulltext.md` 行号）」，然后进下一层。
   部分对必须指出差在哪。
5. 出题阶段**严禁给答案、严禁在题干埋提示、严禁预告下一题**。
6. L4 只考证据链（哪个消融支撑哪个论断），**不考实验设置细节**（数据集 / 超参 / 基线配置），除非我说明要复现该实验。
7. 全部答完后，把结果写入 `notes/$ARGUMENTS/$ARGUMENTS.md` 的 `## 掌握度自测`（层 / 问题 / 我的答案要点 / 判定），
   末尾用不超过 3 行汇报我的薄弱层。
